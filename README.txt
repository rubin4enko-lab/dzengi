ДЕНЮЖКИ: автономная версия (не зависит от Claude)

Что здесь
  index.html            само приложение, один файл
  manifest.webmanifest  описание для установки на экран «Домой»
  sw.js                 нужен, чтобы приложение открывалось без интернета
  icon-*.png            значки

Данные хранятся на вашем устройстве (в памяти браузера). Никаких аккаунтов и серверов.

1. ПЕРЕНЕСТИ ДАННЫЕ ИЗ ВЕРСИИ В CLAUDE
   В старой версии: Настройки, «Сохранить резервную копию (JSON)». Файл сохранится на телефон.

2. ВЫЛОЖИТЬ САЙТ В ИНТЕРНЕТ (бесплатно, пример: GitHub Pages)
   а) Зарегистрируйтесь на github.com и создайте репозиторий (например, denyuzhki).
   б) Нажмите Add file, Upload files, загрузите все файлы из этой папки, нажмите Commit.
   в) Settings, Pages, Source: Deploy from a branch, ветка main, папка /root, Save.
   г) Через минуту сайт появится по адресу https://ВАШ-ЛОГИН.github.io/denyuzhki/
   Подойдут и Cloudflare Pages, Netlify (с аккаунтом): загрузить папку целиком.
   Сайту нужен именно адрес с https, иначе установка и офлайн-режим не заработают.

3. УСТАНОВИТЬ НА IPHONE
   Откройте адрес в Safari, Поделиться, «На экран „Домой“». Дальше открывайте с иконки.
   Данные лучше вести именно из установленной иконки, а не из вкладки Safari:
   Safari может стирать данные сайтов, которыми давно не пользовались.

4. ЗАГРУЗИТЬ ДАННЫЕ
   В новой версии: Настройки, «Загрузить резервную копию», выберите файл из шага 1.
   Это заменит текущие данные.

5. РЕЗЕРВНЫЕ КОПИИ
   Сохраняйте копию раз в месяц: Настройки, «Сохранить резервную копию (JSON)».
   Данные не синхронизируются между устройствами: на каждом они свои.
   Чтобы перенести на другой телефон, сохраните копию и загрузите её там.

6. ОБНОВЛЕНИЯ
   Чтобы изменить приложение, замените index.html в репозитории. Данные не пропадут.
